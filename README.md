# Fit GYM

## Deskripsi

Fit GYM adalah website landing page untuk tempat kebugaran yang dibuat menggunakan HTML, CSS, dan JavaScript.

Website ini dirancang dengan tampilan responsive sehingga dapat digunakan pada perangkat desktop, tablet, dan mobile.

## Tujuan

Project ini dibuat untuk memenuhi tugas Slicing Website dengan menerapkan:

- HTML
- Plain CSS
- JavaScript DOM
- Responsive Design

## Teknologi

- HTML5
- CSS3
- JavaScript

## Fitur Website

### Beranda

Menampilkan informasi utama Fit GYM dan tombol untuk memulai membership.

### Tentang

Menampilkan informasi mengenai Fit GYM serta jumlah program, pelatih, dan anggota.

### Program

Menyediakan beberapa pilihan program latihan:

- Latihan Kekuatan
- Latihan Kardio
- Pelatihan Pribadi

### Harga

Menyediakan tiga pilihan paket membership:

- Dasar
- Standar
- Premium

### Kontak

Menyediakan form untuk mengirim nama, email, dan pesan.

## JavaScript DOM

JavaScript digunakan untuk memberikan interaksi pada website, seperti:

- Membuka dan menutup menu mobile
- Memilih program latihan
- Memilih paket membership
- Validasi form kontak
- Reset form setelah berhasil dikirim

DOM yang digunakan antara lain:

```javascript
getElementById();
querySelectorAll();
addEventListener();
classList.toggle();
getAttribute();
```

## Responsive Design

Website mendukung beberapa ukuran perangkat:

- Desktop
- Tablet
- Mobile

Responsive design dibuat menggunakan CSS Media Query.
